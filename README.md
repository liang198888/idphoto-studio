## 🔧 技术实现方案

### 架构选择：Web服务 + 小程序双轨

```
┌─────────────────┐     ┌─────────────────┐
│   微信小程序     │◄───►│   Node.js后端   │
│  (获客入口)     │     │   (业务逻辑)    │
└─────────────────┘     └────────┬────────┘
         ▲                        │
         │                        ▼
         │              ┌─────────────────┐
         └─────────────►│  现有HTML工具   │
                        │  (离线处理)     │
                        └─────────────────┘
```

### 为什么这样设计？

1. **小程序**：微信生态内传播快，无需安装，支付链路最短
2. **现有HTML保留**：你的v10内核已经很成熟，可以复用于：
   - PC网页版（独立域名）
   - 本地版（用户下载HTML文件离线使用）
   - 隐私保护场景（图片不上传服务器）

## 🚀 实施路线图

### Phase 1: MVP验证（第1-2周）

**目标**：完成首单成交，验证付费意愿

#### Step 1: 注册小程序账号（1天）
1. 访问 [微信公众平台](https://mp.weixin.qq.com/)
2. 注册小程序账号（个人主体即可）
3. 完成实名认证
4. 获取 AppID 和 AppSecret

#### Step 2: 部署后端服务（2-3天）
```bash
cd server
npm install
# 编辑 config.js 填入你的密钥
node server.js
```

**托管选项**：
| 平台 | 费用 | 优势 |
|------|------|------|
| **腾讯云轻量应用服务器** | ¥50-100/月 | 国内低延迟 |
| **阿里云ECS** | ¥80/月起 | 稳定性好 |
| **Railway/Render** | 免费额度 | 海外CDN加速 |

#### Step 3: 开发小程序（3-5天）
参考 `miniprogram/` 目录中的示例代码，在微信开发者工具中导入并调试。

**关键接口对接**：
- 微信登录 → 生成用户ID
- 支付统一下单 → 获取prepay_id
- 支付回调 → 更新订单状态

#### Step 4: 推广测试（第2周）
- 私域群首发体验（你现有的微信群/朋友圈）
- 收集前100单用户反馈
- 调整UI细节

## ⚠️ 合规与风险

### 必须处理的合规事项

1. **用户隐私协议**
   - 明确告知人脸数据处理方式
   - 提供删除数据的入口
   - 建议：处理完即删，不长期存储

2. **内容安全审核**
   - 接入微信内容安全API（¥0.001/次）
   - 过滤违规图片

3. **税务申报**
   - 月收入超¥10,000需注册个体工商户
   - 开通对公账户收款

### 风险应对

| 风险 | 应对措施 |
|------|---------|
| 流量不足 | 小红书/抖音短视频种草 + SEO优化官网 |
| 竞争对手降价 | 聚焦服务质量而非价格战 |
| 支付失败率高 | 接入支付宝备用通道 |
| 法律纠纷 | 购买网络安全保险（年费¥2000+）|
